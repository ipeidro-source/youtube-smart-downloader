# Application icon

The blue/cyan video-and-audio design was selected by the project owner. The original PNG was generated with the built-in image_gen tool and is preserved as `app-icon-source.png`.

Run `python scripts/export_icon.py` to resize and export it without changing its design. The package contains a 256px transparent PNG and a Windows ICO with 16, 20, 24, 32, 40, 48, 64, 128 and 256px sizes. Both the Tk window and PyInstaller use this icon. Unselected brainstorming proposals remain local and are ignored by Git.

## Original generation prompt

Use case: logo-brand. Asset type: one custom Windows desktop application icon for YouTube Smart Downloader, emphasizing choosing the correct audio track. Create ONE polished icon proposal, square canvas. A deep cobalt-blue rounded-square app tile in a refined Windows Fluent aesthetic, with a small amount of dimensional layering. Its central emblem combines a large clean white right-facing play triangle on the left and three bold cyan vertical audio-wave bars on the right, unified as one compact, balanced mark. All elements thick and simple enough to survive 16, 32 and 48 pixels, with strong contrast and generous spacing. Front-on, centered, tile occupies about 82 percent of the canvas. Transparent background outside the tile, no cast shadow outside. No letters, text, flags, numbers, watermarks, grids or mockups. Do not include the official YouTube logo. Exactly one standalone icon.
